## Project Overview

This repository contains my practical database portfolio based on a Social Media Comment System.

The project demonstrates the design, implementation, optimisation and management of relational and NoSQL databases, alongside practical exercises involving transactions, concurrency and distributed database architecture.

The system uses fictional records to demonstrate database operations such as creating posts, managing comments, recording reactions and retrieving engagement data.

## Technologies Used

- PostgreSQL – Relational database implementation
- MongoDB – NoSQL database implementation
- SQL – Database queries and transaction management
- JavaScript – MongoDB operations
- GitHub – Version control and project documentation
